Using this web app

This site is built on the eDocAPI framework (v{{ version }}). The dashboard calls the same document operations you would expose in your own API.

Run the server

From the project root (with eDocAPI installed):

py -m pip install -r webapp/requirements.txt
py -m edocapi.cli.main run webapp.main:app --reload --host 127.0.0.1 --port 8000

Or with the eDocAPI CLI:

py -m edocapi.cli.main run webapp.main:app --reload --host 127.0.0.1 --port 8000

Open http://127.0.0.1:8000 for the landing page and /dashboard for tools.

Dashboard tools

Document-to-PDF conversion works without extra Windows setup. If WeasyPrint cannot load native libraries, eDocAPI automatically creates a readable paginated PDF from the text; styled layout may differ.

  • Convert to PDF — upload DOCX, images, HTML, Markdown, etc.
  • Extract text — returns text in the panel
  • Compress — PDF, JPG/JPEG, PNG, and WebP
  • Merge / Split — PDF operations
  • Document info — metadata dictionary
  • HTML / Markdown → PDF — paste content, no file upload

API endpoints

GET  /api/health
GET  /api/formats
POST /api/convert
POST /api/extract
POST /api/compress?target_size_value=20&target_unit=KB|MB
POST /api/merge
POST /api/split-info
POST /api/extract-pages?start=1&end=3
POST /api/info
POST /api/html-to-pdf          (JSON: {"html": "..."})
POST /api/markdown-to-pdf     (JSON: {"markdown": "..."})

Example: convert with curl

curl -X POST http://127.0.0.1:8001/api/convert \
  -F "file=@report.docx" \
  -o report.pdf
